### 🚀 Sobre Mim

Sou um **Desenvolvedor Front-End** focado em criar aplicações web modernas, intuitivas e otimizadas para conversão. A minha especialidade é construir landing pages funcionais, formulários dinâmicos e interfaces com forte foco na experiência do utilizador (UX/UI) e performance.

- 🎨 **Stack Principal:** React, JavaScript, Tailwind CSS, CSS3, Vite e REST APIs.
- 🗄️ **Bancos de Dados & BaaS:** Experiência prática com **Supabase** (autenticação e bases de dados em tempo real).
- 📈 **Em Evolução & Aprendizagem:** A expandir os meus conhecimentos para o **Back-End** com **Node.js** e **PostgreSQL**.
- 💡 **Foco Atual:** Desenvolvimento Full-Stack, Arquitetura modular e código limpo.
